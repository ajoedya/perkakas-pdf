Kompres PDF

Mengurangi ukuran berkas PDF agar lebih ringan untuk dibagikan atau diunggah. Seluruh pengolahan berjalan di peramban, tidak ada berkas yang diunggah ke server mana pun.

Hasil terbaik bisa didapatkan jika file PDF tidak terlalu banyak gambar. Apabila file PDF yang dikompresi terdapat banyak ornamen atau gambar, besar kemungkinan file hasil kompresi malah jauh lebih besar. (Fitur ini masih dalam pengembangan).

Langkah 1

Pilih berkas

Seret satu atau beberapa berkas PDF ke sini atau klik untuk memilih, bisa dipilih berkali-kali

    Langkah 2

    Kompres menjadi PDF

    Tiap PDF menghasilkan satu berkas PDF terkompresi. Hasil akan muncul di daftar bawah, lalu gunakan tombol Unduh agar unduhan tidak diblokir oleh peramban.
